# Button

Triggers an action on the current page, such as submitting a form, opening a dialog, or toggling something. It renders a native `<button>` and accepts all button attributes.

<Primary />

## When to use

- For actions that happen on the current page.
- Use **one primary button** per view for the main action, and secondary buttons for the rest.

## When not to use

- **To navigate to another page or route:** use `LinkButton`. A button that navigates is announced as a button, so screen reader users won't expect the page to change.
- **For inline links within text:** use a plain `<a>`.

## Variants

### Primary

The main action in a view, such as "Save" or "Send". Set `primary`.

<Canvas of={ButtonStories.Primary} />

### Secondary

The default. For other actions, such as "Cancel" or "Show more".

## Accessibility

**Handled by Button:**

- A native `<button>`: it's focusable, works with Enter and Space, and is announced as a button.
- A visible focus ring for keyboard users only, via `:focus-visible`.

**Your responsibility:**

- **Label:** make it describe the action ("Save changes", not "Click here"). For icon-only buttons, add an `aria-label`.
- **`type`:** inside a `<form>`, a button submits the form by default. Set `type="button"` for anything that shouldn't submit.
- **Disabled state:** a `disabled` button currently looks the same as an enabled one, with a pointer cursor and hover lift. Prefer keeping the button enabled and explaining what's missing when it's pressed. If you do disable it, tell users why nearby.
- **Motion:** the hover lift is a 2px movement and doesn't respond to `prefers-reduced-motion`.

## Do and don't

- **Do** keep labels short, and start them with a verb.
- **Do** use `--themed-component-button-*` properties to change colours or radius. See [Theming](?path=/docs/theming--docs).
- **Don't** use more than one primary button in a group.
- **Don't** restyle a button with inline `style` overrides. They bypass theming and dark mode.
- **Don't** use the `icon` prop. It's experimental, behind a feature flag.
