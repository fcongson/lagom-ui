Add `ImageGallery`, `ImageGalleryRow` and `ImageGalleryItem`: rows of captioned images that share a height in each row, without cropping. Each row has as many images as it has items (up to 3, or 4 with `fullwidth`), and the gallery stacks to one image per line on narrow screens, using CSS only. Supports `emphasized` and `fullwidth`, like `ImageCaption`.
